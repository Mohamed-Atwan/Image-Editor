# 🖼️ Image Editor

A browser-based image editing tool built with vanilla JavaScript, focused on a smooth, responsive UI that gives instant visual feedback while editing.

🔗 **Live Demo:** https://image-editor-three-puce.vercel.app
📦 **Repo:** https://github.com/Mohamed-Atwan/Image-Editor

---

## ✨ Features

- 🎛️ Real-time image filter adjustments with instant visual feedback
- 💾 Download functionality to export the edited image
- 🔄 Reset functionality to instantly revert all filters
- 📱 Responsive, user-friendly interface

---

## 🧰 Tech Stack

- **JavaScript** – Core logic
- **HTML** – Structure
- **CSS** – Styling

---

## 🚀 Getting Started (Run Locally)

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mohamed-Atwan/Image-Editor.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd Image-Editor
   ```

3. **Open `index.html` directly in your browser**, or run it with a local server (e.g. the Live Server extension in VS Code) for the best experience.
